# 🌸 五十音卡片学院 (Japanese Kana Cards)

一个纯前端的日语五十音学习小工具，**零基础友好，双击即用，无需联网、无需安装任何东西**。

## 访问地址

👉 https://（你的GitHub用户名）.github.io/japanese-kana-cards/

## 功能

- 📚 **卡片图鉴** —— 平假名全集（清音46 + 浊音/半浊音25），点击查看大卡片、记忆口诀、发音
- 🃏 **翻卡练习** —— 翻面卡片自测读音，支持洗牌；键盘：空格=翻面，A/D=切卡
- 🎯 **打怪测验** —— 四选一测验，记录连对、正确率与易错假名（本地保存）
- 🐱 猫老师陪你学习，卡片内置中文记忆口诀
- 🔊 发音使用浏览器自带日语语音（离线可用；无声则说明系统缺语音包，不影响其他功能）

## 使用

- 在线使用：直接打开上方网址
- 离线使用：下载 `index.html` 到本地，双击打开即可

## 说明

单文件、无任何外部依赖，适合所有想从零开始学日语 / 备考JLPT的朋友。
